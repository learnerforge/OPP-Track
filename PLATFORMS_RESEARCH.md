## Scraping Considerations

| Factor | Notes |
|--------|-------|
| **robots.txt** | Most .gov sites block scraping; Coursera/Udemy block bot access |
| **JS Rendering** | SWAYAM, NPTEL, Buddy4Study require headless browser |
| **Authentication** | NSP, FAFSA, Grants.gov require login; some data behind auth |
| **Rate Limits** | Coursera API has rate limits; public APIs free-tier limited |
| **Data Freshness** | Scholarship deadlines change frequently; scrape monthly minimum |
| **Legal** | Terms of Service vary; academic/research use generally more tolerated |
